# QR-QURS regression: Monte Carlo simulation

These scripts reproduce the fixed-design simulation for quantile regression
with the Quantile Unit Rational Sine distribution. For a fixed quantile
level `tau`, the conditional quantile is `plogis(X %*% beta)`. Responses
are generated by inverse transform sampling, and coefficients are estimated
by maximum likelihood using `Rsolnp::gosolnp()`.

## Scenarios

| Scenario | Intercept | Covariates | True coefficients, in design-matrix order | Configuration IDs |
|:--|:--|--:|:--|:--|
| R1 | Yes | 2 | (0.50, 0.30, 0.20) | 1–20 |
| R2 | No | 4 | (0.05, -0.27, -0.81, 0.05) | 21–40 |
| R3 | No | 6 | (0.045, 0.03, -0.27, -0.05, -0.81, 0.05) | 41–60 |
| R4 | Yes | 2 | (0.50, 0.30, 0.20) | 61–80 |

Each scenario crosses four sample sizes (50, 100, 200, 400) with five
quantile levels (0.10, 0.25, 0.50, 0.75, 0.90). The covariates in R1–R3
are generated from independent uniform distributions on (0, 1). R4 uses
uniform marginals coupled by a Gaussian copula with latent correlation
0.80. A seeded base design is generated once; smaller designs use the
first rows of the largest design. The design is held fixed across
replications. The base simulation seed is 20260817 and the design seed
is 220260817.

The article reports R1 and the Supplementary Material presents R1–R3.
R4 is an additional correlated-covariate experiment included in the
archived run. The archived replication log records 5,000 valid
replications per configuration and zero discards for all 80
configurations, for 400,000 accepted replications. R1–R3 account for
60 configurations and 300,000 accepted replications.

## Scripts

| Script | Purpose |
|:--|:--|
| `01_FUNCOES_RQ_QURS_GOSOLNP.R` | Distribution functions, log-likelihood, derivatives, estimation, and conditional-quantile prediction |
| `02_MOTOR_MONTE_CARLO_RQ_QURS.R` | Scenarios, fixed designs, replication checks, checkpoints, and aggregate summaries |
| `03_SIMULACAO_RQ_QURS_GOSOLNP.R` | Entry point for the simulation |
| `04_VALIDACAO_RQ_QURS_GOSOLNP.R` | Numerical checks and small runs that test rejection and checkpoint recovery |
| `05_TABELAS_GRAFICOS_RQ_QURS_GOSOLNP.R` | LaTeX tables, boxplots, standardized densities, and performance plots |

The archived run used R 4.5.3 and Rsolnp 2.0.1. Install Rsolnp
with `install.packages("Rsolnp")`. The validation also uses `numDeriv`
when installed to cross-check the observed information.

## Run from this directory

First run the numerical validation and a small simulation for R1. The
test mode targets 20 valid replications per configuration. Reporting
requires all 20 configurations of a scenario to be complete.

```sh
Rscript 04_VALIDACAO_RQ_QURS_GOSOLNP.R
Rscript -e 'options(QRQURS.mode="teste", QRQURS.scenarios="R1"); source("03_SIMULACAO_RQ_QURS_GOSOLNP.R")'
Rscript 05_TABELAS_GRAFICOS_RQ_QURS_GOSOLNP.R teste_rq_qurs_gosolnp_v1_validas_R20
```

Run the full archived design (R1–R4) and generate its report:

```sh
Rscript 03_SIMULACAO_RQ_QURS_GOSOLNP.R
Rscript 05_TABELAS_GRAFICOS_RQ_QURS_GOSOLNP.R
```

To run R1–R3 only, use the following commands. The suffix keeps this
selection separate from the full archive.

```sh
Rscript -e 'options(QRQURS.scenarios=c("R1","R2","R3"), QRQURS.suffix="_article"); source("03_SIMULACAO_RQ_QURS_GOSOLNP.R")'
Rscript 05_TABELAS_GRAFICOS_RQ_QURS_GOSOLNP.R final_rq_qurs_gosolnp_v1_validas_R5000_article
```

Set `QRQURS.workers` above one to run configurations in parallel.
Rerun the same command to resume from checkpoints. Use a new
`QRQURS.suffix` after changing settings, helper code, or software versions.

## Estimation and outputs

The default optimizer uses five restarts and 200 simulated candidates.
Replications are checked for convergence, a sufficiently small gradient,
positive-definite and adequately conditioned observed information, finite
positive standard errors, and valid intervals. Attempt logs record
rejected runs and their reasons. The summaries include mean, bias,
empirical SD, MSE, and empirical coverage of 95% Wald intervals for
coefficients. Separate output summarizes conditional-quantile predictions.

The scripts write designs, replication counts, summaries, and checkpoints
under `RESULTADOS_MONTE_CARLO/`. By default the final folder is
`final_rq_qurs_gosolnp_v1_validas_R5000`. Post-processing writes to
`TABELAS_E_GRAFICOS/` within the selected run. Density plots center and
scale estimates within each coefficient and configuration. The archived
CSV field names and output file names are retained for compatibility.
